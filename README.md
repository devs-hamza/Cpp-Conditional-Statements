- Basic input validation and comparisons

### 2. Switch — 8 Programs
Programs **01–08** focus on:
- `switch`
- `case`

- `default`

### 3. Nested If / Else If / Else — 9 Programs
Programs **01–09** focus on using nested conditional statements.
